# 🐾 CanHappy Grooming - Peluquería Canina

Sitio web para la gestión de servicios de peluquería e higiene canina. Proyecto desarrollado con HTML, CSS y JavaScript para la asignatura **Desarrollo Fullstack II**.

---

## 💻 Tecnologías Utilizadas

* **HTML5:** Estructura semántica del sitio.
* **CSS3:** Diseños y estilos responsivos.
* **JavaScript:** Validaciones de formularios y lógica del lado del cliente.
* **XAMPP:** Servidor local para despliegue web.

---

## 📂 Estructura del Proyecto

* `/admin`: Panel de administración (servicios y usuarios).
* `/css`: Hoja de estilos global (`estilos.css`).
* `/js`: Scripts de validación (`validaciones.js`).
* `/img`: Imágenes del sitio.
* Vistas principales HTML (`index.html`, `productos.html`, `login.html`, `registro.html`, `contacto.html`, etc.).

---

## 🚀 Cómo ejecutar el proyecto con XAMPP

1. Clona o copia la carpeta de este proyecto dentro del directorio de XAMPP:
   `C:\xampp\htdocs\peluqueria-canina`
2. Abre el **XAMPP Control Panel** e inicia el servicio **Apache** haciendo clic en **Start**.
3. Abre tu navegador web e ingresa a la siguiente dirección:
   `http://localhost/peluqueria-canina`
